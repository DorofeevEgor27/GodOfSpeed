# Повороты: угол, прокачка и проверка

20 октября 2026. Сцена владельца: `Assets/Scenes/SupeAngle.unity`.

## Правила владельца

- Угол изменения направления 0–180°. Прямая — 0°, без замедления; всё выше 180° насыщается до 180°, а не заворачивается обратно.
- До 30° влияние минимальное; далее оно постепенно усиливается.
- На 180° потеря 90% при Turns 0 и 40% при Turns 100. После 100 улучшение затухает, потеря не может стать меньше 15%.
- Повороты 40–60° с достаточной прокачкой можно проходить без игрового штрафа.
- Постоянный Turns 0–100; карточки могут дать эффективный уровень выше 100.

## Реализованная формула, начальная настройка для оценки

`A = clamp(abs(угол), 0, 180)`, `L = max(эффективный Turns, 0)`.

```text
S = (A / 180)²
D = 0,90 − 0,005 × L                         при L ≤ 100
D = 0,15 + 0,25 × 2^(-(L − 100) / 100)       при L > 100
R = 0,05 × clamp(L / 100, 0, 1)
Потеря = max(0, S × D − (1 − S) × R)
Лимит скорости = максимум на прямой × (1 − Потеря)
```

Квадрат угла делает влияние малых углов небольшим. Компенсация `R` позволяет полностью убрать штраф плавного поворота; на 180° она не действует. До 100 потеря линейно снижается, пока не станет нулевой. После 100 оставшийся запас улучшения на 180° сокращается вдвое каждые 100 уровней. Конкретная кривая между заданными владельцем ориентирами — начальная настройка, не окончательный баланс.

## Как определяется поворот

- При подготовке сплайна строится профиль в мировых координатах. Один поворот — непрерывное изменение направления в одну сторону, до прямого участка или смены направления изгиба. Суммируются изменения касательной, а не угол между случайными соседними узлами. В конце сумма насыщается до 180°.
- Закрытый путь соединяет части одного поворота через шов начала/конца. S-образные изгибы разделяются по направлению.
- Числовой допуск 0,001° на шаг отсеивает погрешность расчёта. Профиль создаётся один раз, а не заново каждый физический кадр. Изменение геометрии требует перестроения профиля/повторного Play.
- Торможение планируется до начала поворота: `sqrt(Vповорота² + 2 × a × расстояние)`, с запасом на реакцию колёс. Разгон и физические тормоза сохраняются; скорость не назначается Rigidbody напрямую.
- Ближайшая позиция ищется только на физически доступном участке текущей ветки. Глобальный поиск используется при начальной привязке, но не в каждом кадре шпильки.

## Отдельный физический предел

Угол сам по себе не гарантирует проходимость: у двух одинаковых углов могут быть разные радиусы. Сохраняется защитное ограничение по локальной кривизне и боковому ускорению, с предварительным торможением. Поэтому процент формулы — разрешённый игровой максимум, а не обещание фактической скорости в любой геометрии. На тесном изгибе фактическая скорость может быть ниже. На прямой ограничения поворотов нет.

Для режима сплайна с характеристиками физический потолок теперь одинаков для всех Turns: 10,9 юнита/с² (прежнее значение на уровне 100), а не повышается вместе с уровнем. Предел руления 55°, скорость руления 120°/с, дистанция точки упреждения — две колёсные базы. Это техническая настройка следования траектории. Режим Target Object и машины без конфига сохраняют старые 18° и 45°/с.
