# Проверка скорости — 20 октября 2026

Реализовано по решению владельца: уровень скорости 0 соответствует 70 юнитам сцены в минуту, уровень 100 — 200. В HUD используется игровая подпись `km/h`; числовое показание соответствует юнитам в минуту.

## Изменения

- В GlobalGameConfig скорость задаётся двумя полями: «Скорость на уровне 0» и «Скорость на уровне 100». По умолчанию 70 и 200. Формула линейная, выше эффективного уровня 100 продолжается без обрезания. В движение скорость переводится делением на 60.
- Слайдер постоянного уровня скорости допускает 0–100. Остальные три слайдера и их физические настройки на этом этапе не менялись.
- CarSpeedDisplay использует фактическую скорость Rigidbody × 60. Имеющиеся оформление, привязка к Main Car и подпись `km/h` сохранены.
- Регулятор удержания скорости получил ограниченную текущим пределом ускорения интегральную коррекцию вблизи целевой скорости. Она компенсирует сопротивление колёс; при торможении и остановке сбрасывается.
- Процентный расчёт эффективного уровня записан без промежуточного сложения с 1, чтобы 100 + 10% давало ровно 110, а не 111 из-за погрешности double перед округлением вверх. Для скорости 110 формула даёт 213 юнитов/мин. Это проверка формулы, отдельного заезда с карточкой в этой задаче нет.
- Старый показатель CurrentSpeedKmh оставлен только для существующего расчёта топлива. Формула топлива и множитель пустого бака 0,2 не перенастраивались. При пустом баке снижение скорости по-прежнему действует.

## Сценарий

Открытый Unity 6000.3.7f1, сцена владельца `Assets/Scenes/SuperSpeed.unity`, сплайн длиной около 1944 юнитов. Использована единственная активная Main Car — Car_RedBox. Ускорение, поворот и топливный уровень во всех случаях остались 1/1/1. Временные уровни скорости менялись только в Play Mode.

Для каждой строки одинаковые исходная позиция и ориентация, нулевая начальная скорость и полный бак. После 10 игровых секунд разгона скорость измерялась ещё 10 секунд. Фактическая скорость Rigidbody дополнительно сверена с перемещением за интервал. Изменение кадров подтверждено серверной проверкой Time.frameCount; во время измерения каждой строки обновилось более 3700 кадров.

| Уровень | Цель, юн/мин | Rigidbody, юн/мин | По перемещению, юн/мин | HUD |
| --- | ---: | ---: | ---: | ---: |
| 0 | 70 | 70,000 | 69,930 | 70 km/h |
| 1 | 71,3 | 71,300 | 71,353 | 71 km/h |
| 50 | 135 | 135,000 | 134,932 | 135 km/h |
| 100 | 200 | 200,000 | 199,931 | 200 km/h |

Допуск независимого замера по перемещению — 0,5 юн/мин; округлённая фактическая скорость должна совпасть с округлённой целью. Все четыре строки прошли. Небольшая разница замера по перемещению связана в том числе с шагами физики и чтением позиции в кадрах редактора. Снимок HUD на 200 просмотрен.

До коррекции крейсерской скорости при тех же настройках наблюдались 69,307 / 70,594 / 133,663 / 197,952 юн/мин; спидометр показывал 69 / 71 / 134 / 198. Сопротивление Rigidbody в заезде было 0; недобор компенсирован обратной связью по фактической скорости в колёсном контроллере.

## Сохранность и ограничения

После проверки Unity возвращён в Edit Mode. Активность, уровни, позиции, ориентации и сериализованные настройки всех пяти объектов машин совпали с состоянием до теста при сравнении по именам. Исходный флаг несохранённых правок SuperSpeed остался true; сцена на диск не сохранялась. runInBackground восстановлен в false. Файлы SuperSpeed и ForestStudy проверены по SHA-256 на неизменность. Console: compilationFailed=false, 0 ошибок, 0 предупреждений.

Полные замеры: `artifacts/SpeedVerification/Verification.json`, исходные — `Baseline.json`, изображение — `Speed-200.png`. Повторяемый сценарий — `tools/VerifySpeedRange.cs`. Сценарий запускается через eval_file в Play Mode на SuperSpeed, выбирает активную Main Car и записывает промежуточный JSON в SessionState по ключу SpeedWork.ProbeReport. После завершения нужно выйти из Play Mode, чтобы вернуть исходные настройки сцены.

Новая настройка проверена на прямой SuperSpeed. Баланс ускорения, поворотов, топлива и прохождение лесной трассы в эту задачу не входят. Старт с клавиши пробела сохранён. Существующий уровень 1 у машины сцены сохранён: он теперь соответствует 71,3 юн/мин; для проверки крайних значений установить «Скорость» 0 или 100.
