# Скорость и топливо в интерфейсе — 14 октября 2026

В ForestStudy добавлен RaceHUD по образцу владельца: справа снизу крупная белая скорость с km/h, подпись Gas и тонкая зелёная шкала топлива. Владелец выбрал красную машину; только она отмечена Main Car. Canvas масштабируется относительно 1920 × 1080 и привязан к правому нижнему углу. Шкала не интерактивна и не перехватывает нажатия.

Расширен существующий CarSpeedDisplay: он использует фактическую скорость и отношение CurrentFuel / FuelCapacity. При отсутствии активной Main Car весь блок скрывается. При отсутствии бака скрывается только строка топлива. В начале задачи компонент CarFuelTank отсутствовал в Car_Base и у четырёх машин; подключение восстановлено в общей базе и проверено на диске после выхода из Play Mode.

Проверки:

- Компиляция Unity успешна.
- Просмотрен снимок Game View с композитным интерфейсом, 1280 × 720: блок виден справа снизу, текст и шкала не обрезаны.
- При остатке 250 из 500 Slider показывает 0,5; при нуле показывает 0.
- В движении скорость 4,948 км/ч отображалась как 5 km/h, остаток 375,6927 соответствовал заполнению 0,75138545. Телеметрия — artifacts/CarHud/moving.json.
- При выключении красной машины прозрачность блока становится 0.
- После проверки редактор возвращён в Edit Mode, сцена сохранена; красная машина активна, у всех четырёх есть бак.
- Во время подключения после входа в Play Mode произошёл один тайм-аут Unity Pipeline. Повторный запрос завершился успешно. В Console осталась запись этого тайм-аута; ошибок игрового кода или компиляции не обнаружено.

Копии затронутых файлов до изменений находятся в artifacts/CarHud/Before. Исходный шрифт SpeedFont сохранён; HUD использует уже установленный LiberationSans SDF, поскольку в SpeedFont отсутствуют латинские символы подписей образца. Автоматическое изменение не относящегося к задаче Mobile_RPAsset при сохранении редактором отменено, его промежуточная копия находится в artifacts/CarHud.
